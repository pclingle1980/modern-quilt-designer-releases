# Modern Quilt Designer

Official Windows installers and update metadata. Application source remains private.

[Download 0.7.1 Preview](https://github.com/pclingle1980/modern-quilt-designer-releases/releases/download/v0.7.1-preview/Modern-Quilt-Designer-0.7.1-Windows-x64-Setup.exe)

Save your work, close the old app, and run Setup once. In the new app, open **Help → Check for Updates**, choose **Preview / Development** for testing builds, then **Check for updates**. When a newer version is available, choose **Download & install**. The app verifies the signed installer before installation and asks you to save unfinished work. After restart, choose **Restore design** to continue your open quilt.

Stable and Preview are separate channels. There is no stable release feed until a stable build is published. Ordinary design work remains offline. No subscription or developer tools are required.

These preview installers do not yet have a Windows Authenticode certificate and may show SmartScreen. Update signatures verify installers inside the app; they do not remove Windows SmartScreen warnings.
